# 📚 Planificador y Gestor de Tareas Académicas

Aplicación web para ayudar a los estudiantes a organizar sus tareas, asignaturas y exámenes en un mismo lugar.

El objetivo del proyecto es facilitar la organización de las actividades académicas y permitir al alumno consultar sus tareas pendientes y próximos exámenes de una forma sencilla.

## 🛠️ Tecnologías utilizadas

* **Java** - Lenguaje de programación principal.
* **Spring Boot** - Framework utilizado para desarrollar la aplicación web.
* **MySQL** - Base de datos para guardar la información.
* **HTML y CSS** - Para crear la interfaz de la aplicación.
* **Eclipse** - Entorno de desarrollo.
* **Git y GitHub** - Para controlar las versiones del proyecto.
* **Trello** - Para organizar y hacer un seguimiento del trabajo.

## 📌 Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Gestión de asignaturas.
* Gestión de tareas.
* Gestión de exámenes.
* Consulta de tareas pendientes.
* Consulta de próximos exámenes.

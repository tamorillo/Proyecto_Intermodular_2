# 📚 Proyecto Intermodular II

Bienvenido/a al repositorio del módulo Proyecto Intermodular II de Desarrollo de Aplicaciones Multiplataforma (DAM).

Este repositorio tiene como finalidad organizar y documentar el trabajo realizado durante el módulo, permitiendo llevar un seguimiento de los avances y cambios realizados a lo largo del desarrollo de los proyectos.


## 📂 Contenido del repositorio
En este repositorio encontrarás los archivos y recursos relacionados con el desarrollo del proyecto:

* **💻 Código fuente**: archivos y clases necesarios para el funcionamiento de la aplicación.
* **📖 Documentación técnica**: información sobre la estructura, configuración y funcionamiento del proyecto.
* **🗄️ Base de datos**: configuración y recursos relacionados con el almacenamiento de datos.
* **📅 Seguimiento del desarrollo**: avances y modificaciones realizados durante los diferentes sprints.

## 🔄 Metodología de trabajo
El desarrollo del proyecto se organiza mediante sprints, siguiendo una metodología de trabajo incremental.

Se utiliza Git y GitHub para el control de versiones, registrar los cambios de forma progresiva y mantener un historial del trabajo realizado.

## 📌 Objetivo del repositorio
Mantener organizado el trabajo realizado durante el módulo, facilitar el acceso al código y a la documentación, y mostrar la evolución del proyecto a lo largo de su desarrollo.
